# Litology :D
> The study and practice of transforming imagination into written literature.

Litology is an online editor for beginning authors. It hosts essential document editing tools, combined with book writing specific tools to make writing as easy as possible.

Target audience:
For a prototype app, just authors. But because literature spans a large topic, it can also be expanded to students, teachers, used in book clubs, etc.
